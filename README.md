# Quant Desk KR

한국 주식 주간 멀티팩터 전략을 점검하는 개인용 Streamlit 앱의 첫 버전입니다.
로컬 브라우저에서 실행됩니다. 샘플 전략은 80개 가상 종목을 사용하며,
별도의 실제 주가·재무정보 화면에서 자료를 수집하고 저장할 수 있습니다.

## 실행

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 127.0.0.1
```

또는 PowerShell에서 `./start.ps1`을 실행합니다. 기본 주소는 http://127.0.0.1:8501 입니다.

## 제공 기능

- 팩터 비중 조절, 종목 순위와 업종 필터
- 보유 수량과 현금 입력 및 로컬 저장
- 목표 20종목, 기존 보유 30위 유지, 정수 수량의 매매 제안
- 최소 10만원 거래, 거래비용 여유분과 현금 제한 반영
- 매매 제안 CSV 다운로드와 메모 기록

기존 보유가 30위 이내면 우선 유지하고, 남은 자리를 상위 20위에서 채웁니다.
유지 대상이 20개를 넘으면 상위 20개만 유지합니다. 조건 통과 종목이 부족하면 남는 비중은 현금입니다.
10만원 미만 매도도 생략하므로 탈락 종목이 잔여 보유로 남을 수 있습니다.
거래비용 기본 0.3%는 매수·매도 공통의 임의 여유분이며 실제 세율을 의미하지 않습니다.

보유 내역과 제안은 `data/quantdesk.db`에 저장됩니다. 제안 저장은 보유 수량을 변경하지 않습니다.
팩터 설정은 현재 세션에서 조절하며 저장한 제안에는 당시 설정도 보관됩니다.

## 시점고정 백테스트

왼쪽 **백테스트** 화면은 과거 시점에 실제로 알 수 있었던 입력만 사용하는 주간 백테스트 엔진입니다.
먼저 실행 준비 상태를 검사하며, 아래 입력이 모두 갖춰지고 모든 주차에 유효 후보가 80종목 이상일 때만
**백테스트 실행** 버튼이 활성화됩니다.

- 각 신호일의 KOSPI·KOSDAQ 보통주 종목군과 시가총액·거래대금 스냅샷
- 성과 시작 전 최소 252거래일을 포함한 종목별 일별 시가·종가
- 당시 공시일이 확인된 연간 재무제표와 KRX/OpenDART 기업 대조 자료
- 같은 기간의 KOSPI·KOSDAQ 지수 가격과 검증 상태가 기록된 기업행사 자료

신호는 매주 마지막 거래일 종가까지의 정보로 만들고 다음 거래일 시가에 체결합니다. 초기자금은 1,000만원,
목표는 20종목 동일비중, 기존 보유는 30위까지 유지하며 정수 수량과 최소 주문 10만원을 적용합니다.
완료 결과에는 입력 fingerprint, 주차별 순위·보유·공시·제외 사유·거래 기록이 함께 저장됩니다.
한 주라도 엄격한 80종목 기준을 통과하지 못하거나 미검증 기업행사가 있으면 실행을 불완전으로 처리하고
CAGR, Sharpe 같은 공식 성과 수치를 표시하지 않습니다.

현재 첫 운영 목표는 최근 3년이며 엔진의 최종 목표는 10년입니다. 실제 3년 실행 전에도 과거 종목군,
상장폐지 포함 가격, 지수, 기업행사 자료를 별도로 수집해야 합니다. 현재 결과는 배당을 제외한 가격수익률이고
무위험수익률은 연 0%입니다. 생존편향을 피하려면 현재 종목 목록을 과거에 소급해 사용해서는 안 됩니다.
상위 100 동일비중 벤치마크는 1,000만원과 최소 주문 10만원으로 100종목을 정수 매수할 수 없는 문제 때문에
팩터 선택 효과 비교용 소수점 수량 모델로 계산합니다.

실행 명령은 다음과 같습니다.

```powershell
python -m streamlit run app.py --server.address 127.0.0.1
```

## 과거 전체시장 데이터 수집

왼쪽 **과거 시장 데이터** 화면은 금융위원회 주식시세정보 OpenAPI에서 날짜별 KOSPI·KOSDAQ
전체 종목의 OHLC, 거래량, 거래대금, 시가총액과 상장주식수를 수집합니다. 현재 종목 목록으로 과거 자료를
필터링하지 않으므로 이후 상장폐지된 종목도 당시 원본에 남습니다.

먼저 공공데이터포털에서 **금융위원회_주식시세정보** 활용신청을 하고 인증키를 발급받습니다.

- 공식 안내: https://www.data.go.kr/data/15094808/openapi.do
- 화면의 인증키 입력란은 현재 Streamlit 세션에서만 사용합니다.
- PowerShell 세션에서 `$env:QUANTDESK_DATA_GO_KR_KEY="발급받은키"`로 설정할 수도 있습니다.
- 실제 키를 `.env.example`, 소스 코드, Git 또는 화면 캡처에 넣지 마세요.

수집 시작일과 종료일을 정하고 **전체시장 수집 시작**을 누르면 별도 로컬 작업 프로세스가 날짜별로 처리합니다.
앱을 새로고침해도 SQLite에 저장된 진행 상태는 유지됩니다. **일시중지**는 현재 날짜가 끝난 뒤 적용되고,
같은 작업은 **재개**할 수 있습니다.

- `승격`: 원본 보관, 형식 검사와 이상치 검사를 통과한 날짜
- `격리`: 종목 수·전체 시가총액·원본 체크섬 또는 열 구조가 예상과 달라 자동 사용이 금지된 날짜
- `실패`: 연결, 인증 또는 원본 형식 오류가 발생한 날짜
- `calendar_unresolved`: 세 번 조회해도 자료가 없어 휴장일인지 확인이 필요한 평일
- `non_session`: 공식 근거로 휴장일임을 확인한 날짜

자동수집이 해결하지 못한 날짜는 공식 CSV로 보충할 수 있습니다. CSV도 자동수집과 동일한 원본 보관,
검증과 승격 절차를 거칩니다. 다른 데이터 제공처의 파일을 공식 CSV처럼 넣으면 안 됩니다.

원본은 `data/raw/krx/daily` 아래에 SHA-256 기반의 압축 파일로 보관되고, 진행 상태와 정규화 자료는
`data/market.db`에 저장됩니다. 둘을 함께 백업해야 합니다. 원본 파일은 Git에서 제외되며 외부에 재배포하지
않습니다. 이 자료는 출처표시·비상업·변경금지 조건의 공공데이터를 개인 연구 목적으로 사용하는 흐름입니다.

이 단계가 완료되어도 공식 백테스트는 열리지 않습니다. 종목 종류와 상장·상장폐지 생애주기, 종목코드 변경,
기업행사와 수정주가를 후속 단계에서 검증한 뒤에만 기존 시점고정 백테스트 입력으로 승격합니다.

## 종목 생애주기 원본과 감사

**과거 시장 데이터** 화면의 **종목 생애주기** 영역은 KRX의 종목 마스터, 신규 상장, 상장 폐지,
식별자 변경 원본을 별도로 보존합니다. 자동 수집이 실패하면 KRX에서 내려받은 공식 CSV를 같은 경로로
검증할 수 있습니다. 업로드 파일을 직접 수정하는 표는 제공하지 않습니다.

KRX가 자동 조회 요청에 로그인 세션을 요구하는 경우 앱은 실패 원인을 표시하고 공식 CSV 업로드를
안내합니다. 이 경우 브라우저의 KRX 화면에서 CSV를 내려받아 해당 자료 종류에 업로드해야 하며,
브라우저 로그인 정보나 쿠키를 앱에 복사하지 않습니다.

- 각 원본은 `data/raw/krx/lifecycle` 아래에 SHA-256 체크섬으로 압축 보관됩니다.
- 같은 조회 범위의 내용이 바뀌면 기존 파일을 덮어쓰지 않고 새 버전으로 남깁니다.
- 변경 버전은 KRX 정정 공지 같은 선택 근거를 입력하기 전까지 생애주기 준비 상태를 잠급니다.
- 상장일은 포함하고 상장폐지 효력일은 제외하며, 최종 매매일은 별도 값으로 보존합니다.
- 종목코드, 종목명, 시장의 유효구간과 사건은 원본 버전 및 원본 행 번호까지 추적됩니다.
- **선택 원본 재빌드 검증**은 보존 원본으로 같은 모델 지문이 재현되는지 확인합니다.

일별 전체시장 자료와 대조할 때 시장 원본에만 있는 종목, 활성 종목의 누락, 명칭·시장 불일치가
검토 항목으로 남습니다. 상장주식수 20% 이상 변화 또는 전 거래일 대비 종가가 0.5배 미만·2배 초과이면
기업행사 검토 신호를 남기지만 자동으로 액면분할이나 상장폐지로 분류하지 않습니다. 거래량 0은 상장 종료
근거로 사용하지 않습니다.

생애주기 준비가 완료되어도 **투자 가능성**, **기업행사**, **공식 백테스트** 잠금은 유지됩니다.
이 단계는 과거 상장 종목군을 감사 가능하게 재구성하는 기반이며, 매매 가능 여부나 수정주가를 확정하지 않습니다.

## 과거 투자 가능성 상태 감사

**과거 시장 데이터** 화면의 **투자 가능성 상태 감사** 영역에서 KRX 공식 상태 자료를 날짜별로 수집합니다.
자동 조회가 로그인이나 접근 제한으로 실패하면 KRX 화면에서 받은 공식 CSV를 해당 날짜에 업로드합니다.
브라우저 쿠키나 로그인 정보를 앱에 입력하지 않습니다. 업로드 파일도 자동 수집과 같은 검증을 거치며,
원본은 `data/raw/krx/investability`에 체크섬 기반 버전으로 보존됩니다.

- `investability-v1` 정책은 KOSPI·KOSDAQ 보통주만 허용하고 관리종목, 매매정지, 정리매매 상태를 차단합니다.
- 공시 시각이 있는 상태는 그 시각 이후에만 사용할 수 있습니다. 날짜만 확인된 상태는 다음 공식 거래일부터 알 수 있었던 것으로 처리합니다.
- 자료가 없거나 충돌하거나 아직 공개되지 않았으면 `unknown`으로 판정합니다. 전날 상태를 자동으로 이어 쓰지 않습니다.
- 금요일 신호 시각의 후보 적격성과 다음 거래일 주문 시각의 거래 가능성은 별도로 확인합니다. 주문 시각에 차단되면 체결하지 않고 이유를 기록합니다.
- 같은 날짜의 공식 자료가 수정되면 새 원본을 보존하고 선택 사유를 입력해야 합니다. **선택 원본 재빌드 검증**과 **생애주기·시장 대조**에서 근거와 충돌을 확인합니다.
- 화면의 네 상태는 종목 생애주기, 투자 가능성, 기업행사, 공식 백테스트를 각각 표시합니다. 투자 가능성 자료가 채워져도 기업행사와 공식 백테스트는 계속 잠겨 있습니다.

SQLite `data/market.db`와 `data/raw/krx` 원본 전체를 함께 백업해야 원본 버전, 선택 사유와 판정을 재현할 수 있습니다.
공식 KRX 화면과 내려받은 자료로 대표 사례 5건을 대조하는 절차는
[`docs/investability-official-audit.md`](docs/investability-official-audit.md)에 기록합니다. 현재 해당 실자료 감사는 보류 상태입니다.

**관리종목 지정·해제 내역 대조**는 KRX Data Marketplace의 개별종목 변경 내역 CSV를 별도로 받습니다.
한 종목을 조회한 원본 CSV를 업로드하면 SHA-256으로 보존하고, 지정·해제 행으로 조회 구간의
관리종목 상태를 재구성합니다. `-`는 그날 사건이 없다는 뜻이며 해제나 정상 상태를 뜻하지 않습니다.
지정·해제 각각의 공시일, 공개 시각(KST), 효력일을 별도로 입력해 CSV 사건 날짜와
효력일을 대조합니다. 공개 시각을 입력해도 원문 시각 검증이나 당시 인지 가능성 검증이
완료된 것으로 취급하지 않습니다.
이 개별종목 자료는 전체시장 일별 상태 자료로 승격되지 않으며 준비 상태의 잠금을 풀지 않습니다.

## 실제 데이터 수집

왼쪽 화면 선택에서 **실제 주가 데이터**를 선택합니다.
종목 목록 갱신 후 최대 50종목을 선택하고 기간을 정해 **선택 종목 주가 갱신**을 누릅니다.
목록을 가져오지 못해도 알고 있는 종목코드로 수집할 수 있습니다.
목록을 갱신한 뒤 **상위 100개 주가 일괄 수집**을 누르면, 실제 멀티팩터 순위와 같은
시가총액 상위 100개 보통주 후보의 주가를 선택 목록과 관계없이 수집합니다.

- FinanceDataReader 0.9.202: KRX 종목 목록, NAVER 일별 OHLCV
- 시가총액·거래대금: 목록 스냅샷. 거래 기준일과 수집 시각은 동일하지 않을 수 있습니다.
- 일별 거래대금은 제공되지 않으며 종가와 거래량을 곱한 값으로 대체하지 않습니다.
- 장중 데이터 제외를 위해 종료일은 어제까지입니다. 마지막 거래일을 화면에서 확인하세요.
- 각 제공처 호출은 35초 제한입니다. 실패 시 기존 데이터와 실패 사유를 남깁니다.
- `data/market.db`에 저장되며 샘플 보유 내역과 분리됩니다.
- 화면을 열기만 하면 저장분을 조회합니다. 버튼을 누르면 선택 기간을 다시 가져와 날짜별로 갱신합니다.
- 수정주가 기준 혼합 위험을 줄이기 위해 요청 기간 전체를 다시 받습니다. 백테스트 전 기업행사 검증이 필요합니다.

- 상위 100개 일괄 수집은 종목별 실패를 기록하고 다음 종목을 계속 처리합니다. 제공처 응답에 따라 몇 분 걸릴 수 있습니다.

## OpenDART 재무정보

왼쪽 **재무정보**에서 발급받은 40자리 인증키를 입력하고 기업 목록을 갱신합니다.
기업, 사업연도, 연결 또는 별도 기준을 선택해 연간 사업보고서 재무제표를 수집합니다.
인증키는 현재 브라우저 세션에서만 사용하며 파일이나 GitHub에 저장하지 않습니다.

기업 목록과 KRX 종목 목록을 갱신한 뒤 사업연도를 선택하고 **상위 100개 재무제표 일괄 수집**을 누르면,
실제 멀티팩터 순위와 같은 시가총액 상위 100개 보통주 후보를 순서대로 수집합니다.
연결 재무제표를 우선하며 조회 자료가 없는 기업만 별도 재무제표로 대체합니다.
종목별 실패는 기록하고 다음 종목을 계속 처리하며, 최근 결과는 재무정보 화면에서 확인할 수 있습니다.
기본 **부족한 종목만** 모드는 선택 연도에 연결 또는 별도 재무제표가 저장된 종목을 건너뜁니다.
정정 공시를 포함해 모든 후보를 다시 확인할 때만 **전체 재확인**을 선택합니다.

재무제표 접수번호와 공시 목록을 대조하고, 목록에서 같은 접수번호를 찾지 못하면 유효한 접수번호의 날짜를 사용합니다.
정정본은 접수번호별로 보관하며 `data/dart.db`는 Git에서 제외됩니다.
실제 인증키를 사용한 100종목 일괄 수집과 로컬 저장을 검증했습니다.
분기·반기와 과거 시점 재현은 다음 단계입니다.

재무정보 화면의 **재무 지표 검증** 표에서 연간 순이익, 당기·전기 자기자본과 ROE를 확인합니다.
연결은 지배기업 소유주 귀속 계정, 별도는 순이익·자본총계 표준 계정만 사용합니다.
기업 대조는 KRX와 OpenDART의 6자리 종목코드가 같고 OpenDART 8자리 법인번호가 유효해야 통과합니다.
공식 약칭·영문명처럼 이름 표기가 달라도 종목코드가 같으면 같은 기업으로 처리합니다.
과거 종목코드나 다른 그룹 회사는 자동 연결하지 않습니다. 기업 선택은 대조된 기업이 기본입니다.
대조되지 않은 기존 자료도 보존하며 제외 이유를 표시합니다.
연간 이익/시가총액은 목록 스냅샷에 대한 참고 비율이며 TTM·우선주·시점 정합성을 반영한 투자 점수가 아닙니다.

공식 안내: https://opendart.fss.or.kr/

## 실제 멀티팩터 순위

왼쪽 **실제 멀티팩터 순위**에서 시가총액 기준 상위 100개 보통주 후보를 확인할 수 있습니다.
KOSPI·KOSDAQ 종목만 대상으로 하고, 우선주·스팩·리츠는 제외합니다.

- 기준일 이전의 최근 252거래일 종가로 12개월 수익률과 연 변동성을 계산합니다.
- 기준일 이전에 공시된 연간 재무제표만 사용하며, 같은 연도에는 연결 재무제표를 우선합니다.
- 종목코드와 DART 법인번호가 확인되고, ROE 및 연간 이익/시가총액이 검증된 종목만 점수에 포함됩니다.
- 모멘텀 45%, 가치 20%, ROE 20%, 저변동성 15%를 후보군 내 백분위로 합산합니다.
- 주가·공시가 부족하거나 기업 대조가 실패한 종목은 제외 사유를 보여줍니다.

### 주간 포트폴리오와 매매 제안

실제 순위 화면의 **주간 포트폴리오** 탭에서 보유 현금과 상위 100개 후보의 보유 수량을 저장할 수 있습니다.
신규 계정은 현금 1,000만원으로 시작하며, 상위 20종목을 종목당 5% 동일 비중으로 계산합니다.
기존 보유 종목은 30위 이내면 유지하고, 최소 주문금액 10만원과 거래비용 여유분 0.3%를 반영합니다.
정수 주식만 사용하므로 1주 가격이 종목당 배정액보다 높으면 해당 종목은 편입되지 않고 현금으로 남습니다.

**매매 제안** 탭은 매도 후 매수할 수량과 예상 금액을 보여주고 CSV로 내려받을 수 있습니다.
실제 보유 내역은 `data/portfolio.db`에 저장되며 샘플 전략 계정과 분리됩니다.

이 화면은 저장된 자료만 읽으며, 데이터 수집 요청이나 실제 주문을 전송하지 않습니다. 현재 시점 연구용 화면이므로
과거 성과를 재현하는 백테스트 용도로 사용하면 안 됩니다.
